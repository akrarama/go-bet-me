# Против (go-bet-me)

Команда: **1669b7714111e1cd1f9cadcfb32867fc**

Ставишь кредиты на себя, ИИ проверяет по веб-камере в прямом эфире, друзья ставят против. Управление только телом, руками и лицом, без клавиатуры и мыши.

Демо: https://akrarama.github.io/go-bet-me/

## Запуск локально

Ничего устанавливать не нужно: чистый JavaScript без сборки. Нужен любой статический сервер, например python3, который уже есть в macOS:

```
python3 tools/serve.py
```

и открыть http://localhost:8000 (камера на localhost работает без HTTPS).

Проверка кода и тесты без Node (JavaScriptCore встроен в macOS): `sh tools/check.sh`.

README дописывается по ходу работы.
